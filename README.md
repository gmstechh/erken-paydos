# 🏃‍♂️ Erken Paydos Animasyonu (Windows Kilitleyici)

Mesai bittiğinde veya bilgisayar başından kalkmak istediğinizde, ekrana bir maskotun gelip metal kepengi çekerek bilgisayarı **otomatik olarak kilitlediği** eğlenceli bir Python betiği.

## 🚀 Özellikler
- Tam ekran, şeffaf arka planlı pürüzsüz animasyon.
- Gerçekçi "Kovboy Kementi" fiziği ve dinamik karakter hareketleri.
- Sokak stili, metal kepenk üzerine yazılmış janjanlı atar yazıları.
- Kepenk indiğinde `ctypes` üzerinden Windows kilit ekranını (LockWorkStation) otomatik tetikler.

## 🛠️ Nasıl Çalıştırılır?
1. Bilgisayarınızda Python yüklü olmalıdır.
2. Klasördeki `paydos.py` dosyasını çalıştırın.
3. Arkada siyah CMD ekranı görmek istemiyorsanız kodu `calistir.vbs` üzerinden veya `pythonw paydos.py` şeklinde çalıştırabilirsiniz.

**Kısayol Tuşu Atamak İçin:** Dosyayı masaüstünüze kısayol olarak gönderip sağ tıklayarak bir klavye kısayolu (Örn: CTRL + ALT + P) atayabilirsiniz.
